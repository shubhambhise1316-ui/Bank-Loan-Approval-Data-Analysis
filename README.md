Bank Loan Approval Data Analysis


Objective

Analyze historical bank application logs to identify high-risk profiles and determine the structural factors driving loan approval decisions.

Tools Used

• SQL (PostgreSQL): For data schema definition, cleaning anomalies, and running multi-level risk aggregations.
• Excel: For rapid data validation, descriptive statistics profiling, and dynamic pivot metrics mapping.
• Power BI: For building the interactive dashboard reporting layer using complex relational DAX measures.

Key Analysis

• Portfolio Health Summarization: Calculating baseline indicators like overall approval percentages and applicant financial distribution spreads.
• Risk Metric Tiering: Segmenting application approval likelihood by credit quality brackets and income ratios.
• Demographic Attribution Matrix: Evaluating how age, relationship status, and employment categories correlate with system overrides.
• Dependency Operational Analysis: Quantifying risk exposure shifts triggered by outstanding loan counts and child dependents.

Key Insights

• Employment Disparity Impact: Employed applicants show significantly higher stability metrics and approval velocity compared to self-employed or unemployed groups.
• Decision Boundary Vectors: Credit score clusters below 500 face automatic high-risk rejection thresholds regardless of income scale.
• Portfolio Concentration Risk: Total dollar-based loan exposure centers heavily in specific relationship categories, showing distinct risk clusters.
• Shift Mismatches Corrected: Resolved data import column alignment bugs (num_dependents offsets) to ensure precise analytics output accuracy.

Conclusion

This project successfully demonstrates an end-to-end data pipeline implementation—taking raw, messy bank records through full database modeling, validation audits, and strategic dashboard production.
